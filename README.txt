VENUS — cara run
1. Unzip, lalu double-click  Venus.xcodeproj  (butuh Xcode 26).
2. Klik project "Venus" (kiri atas) > target Venus > Signing & Capabilities
   - Team: pilih Apple ID kamu
   - Kalau muncul error bundle id: ganti "com.sabilaa.venus" jadi yang unik, mis. com.namakamu.venus
3. Colok iPhone, pilih iPhone di bar atas, tekan Run (Cmd+R).
   iPhone: Settings > Privacy & Security > Developer Mode = ON.
4. Icon & splash: buka Venus/Assets.xcassets
   - AppIcon  -> drag gambar 1024x1024
   - SplashImage -> drag gambar splash (ke slot 3x / 2x / 1x)
